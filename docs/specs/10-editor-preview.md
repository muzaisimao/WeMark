# 子 PRD · M10 编辑区预览

> 所属整体 PRD：`docs/PRD.md` 第 6 节（V1.1）
> 对应任务：T14（编辑区分栏预览，形态 A）
> 状态：设计中

## 1. 背景与目标

「编辑一半想看效果」是源码式 Markdown 编辑器的一大痛点。当前编辑区是纯 textarea，无法预览未发送内容的渲染结果。本模块在**编辑区内**提供「编辑 + 预览」并存能力，且**只作用于编辑区**，不影响渲染区。

## 2. 需求详述（形态 A：分栏预览）

### 2.1 切换入口

- 底部工具栏、发送按钮左侧新增一个**切换按钮**（与草稿箱并排）。
- **图标随状态切换**：
  - 源码模式：显示「眼睛」（语义：去看效果）。
  - 预览模式：按钮高亮，显示「笔/代码」（语义：回到纯源码）。
- idle / editing 两种编辑状态均可见（不挂在「正在编辑」提示条上，因为 idle 态没有该提示条）。

### 2.2 预览模式行为

- 点击切换后，编辑区从单个 textarea 变为**左右分栏**：左栏 = 源码 textarea（继续编辑），右栏 = 渲染预览（实时刷新当前草稿）。
- 预览内容 = **当前编辑区源码**的渲染结果（不是整个文档），复用 M8 的 unified/remark 渲染管线。
- 实时刷新：输入时 debounce（约 200ms）重新渲染右栏。
- 草稿内容原样保留，切换、编辑、预览之间不丢失。

### 2.3 编辑区展开

- 编辑区默认高度有限，分栏后每栏偏矮；切换到预览模式时，编辑区**临时自动展开**到更大高度（如编辑器最大高度，或占渲染区一定比例）。
- 切回源码模式时，编辑区**还原**到切换前的高度。
- 展开/还原不改变用户拖拽设定的 `editorHeight`（临时态独立于持久化值）。

### 2.4 边界

- 预览栏**只读**，不可编辑。
- 发送按钮在预览模式始终可用：点击发送 = 以当前源码为准发送（预览结果不作为发送内容）。
- 取消编辑 / Esc 行为不变。

## 3. 形态 B（真·所见即所得，未来方向，不在本期实现）

> 记录在此，作为后续迭代方向，届时引入第三方编辑器内核。

- 目标形态：光标直接在渲染结果上编辑，背后自动生成 Markdown（Typora 风格），编辑区成为所见即所得编辑器。
- 触发：可能作为「编辑 / 预览」之外的第三种模式，或独立开关。
- 技术预研方向：引入基于 ProseMirror 的编辑器内核（如 Milkdown / Tiptap），与本项目的「聊天式块级」数据模型对接。
- 暂不纳入 T14，仅在架构上预留「块 ↔ 编辑器内核」的可替换边界（M8 的 `Block` / mdast 已为此打底）。

## 4. 验收标准（形态 A）

- [ ] 工具栏出现切换按钮，图标随模式切换，idle / editing 均可用。
- [ ] 切换到预览模式后，编辑区变左右分栏：左源码可编辑、右预览实时刷新当前草稿。
- [ ] 切换时编辑区自动展开，切回源码还原高度，且不覆盖用户拖拽设置。
- [ ] 预览只读，发送以源码为准，草稿不丢失。
