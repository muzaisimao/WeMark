# 子 PRD · M5 编辑区与快捷工具栏

> 所属整体 PRD：`docs/PRD.md` 第 4、6 节
> 对应任务：T7
> 状态：已完成

## 1. 背景与目标

编辑区是 Markdown 源码的输入框，底部工具栏提供常用格式快捷操作与图片上传，让用户无需记忆 Markdown 语法即可快速排版。

## 2. 需求详述

### 2.1 输入框

- 多行文本输入，高度随内容自动增长（有上限，超出滚动）。
- Enter 发送 / Shift+Enter 换行（与 M3 一致）。
- 编辑目标提示条（「正在编辑：第 N 块」+ 取消），见 M3。

### 2.2 快捷格式

工具栏对选中文本/光标处提供：
- 加粗、斜体、删除线
- 标题（H1–H6）
- 无序/有序列表、任务列表
- 行内代码、代码块
- 引用、链接、图片、表格
- 快捷键映射（Cmd/Ctrl+B 加粗等）

### 2.3 图片上传

- 「图片」按钮打开文件选择器，选中图片后插入。
- MVP：本地图片以相对路径插入，或复制到文档附件目录；后续支持图床。

### 2.4 工具栏布局

- 底部工具栏：左侧格式按钮组，右侧「草稿箱」「发送」。
- 草稿箱入口见 `specs/03-block-editing.md` 3.5。

## 3. 验收标准

- [x] 输入框 Enter/Shift+Enter 行为正确，高度自适应。
- [x] 各快捷格式按钮能正确插入/包裹 Markdown 语法。
- [x] 图片上传能插入图片语法。
- [x] 草稿箱入口与发送按钮在工具栏可见可用。
