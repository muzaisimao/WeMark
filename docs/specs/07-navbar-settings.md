# 子 PRD · M7 功能栏与设置

> 所属整体 PRD：`docs/PRD.md` 第 4、6 节
> 对应任务：T9（功能栏与设置）、T10（主题切换与持久化）
> 状态：已完成

## 1. 背景与目标

最左侧功能栏放置全局/低频操作图标与设置入口；设置面板承载主题、字体等偏好项。本模块由两个任务组成：

- **T9 功能栏与设置**：完善功能栏图标布局，提供可打开、可交互的设置面板。
- **T10 主题切换与持久化**：深色/浅色/跟随系统三种主题，切换即时生效并持久化。

## 2. 需求详述

### 2.1 功能栏（T9）

- 竖排图标，分上下两区：
  - **顶部**（全局/低频操作）：新建文档、打开文档、打开目录（T8 已接线）。
  - **底部**：设置。
- 图标 hover 高亮 + `title` tooltip 提示。
- 分工边界：功能栏放**全局/低频**操作；渲染区右上角放**当前文档相关**操作（复制/导出）。

### 2.2 设置面板（T9）

- 点击底部「设置」图标打开设置面板（居中模态弹窗）。
- 面板结构：标题「设置」+ 关闭按钮 + 分组表单。
- 设置项（MVP）：

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 主题 | 单选（深色/浅色/跟随系统） | `system` | 切换即时生效 |
| 编辑器字号 | 数字（12–24） | `14` | 影响编辑区输入框 |
| 代码字号 | 数字（11–20） | `13` | 影响代码块 |
| 默认文档目录 | 路径文本 | 空 | 「打开目录」的默认起点（后续接入） |

- 关闭方式：点关闭按钮、点遮罩、按 `Esc`。

### 2.3 主题切换（T10）

- 三种模式：**深色** `dark`、**浅色** `light`、**跟随系统** `system`。
- 实现方式：CSS 变量双主题，通过 `<html data-theme="dark|light">` 切换。

  - `:root`（深色，现有变量，见 `src/styles/theme.css`）作为 `dark` 基准。
  - 新增 `[data-theme="light"]` 覆盖块，定义浅色变量（浅灰背景 + 深色文字，accent 保持微信绿 `#07c160`）。
- 「跟随系统」：监听 `window.matchMedia("(prefers-color-scheme: dark)")`，系统变化时自动在 dark/light 间切换。
- 切换即时生效，无需重启。

### 2.4 设置持久化（T10）

- 设置项存储于 `localStorage`，key 为 `wemark.settings`（与 `layout` store 的 `wemark.layout` 一致）。
- 启动时读取并应用；变更时防抖写入（参考 `src/stores/layout.ts` 的写法）。
- 数据模型：

```ts
type ThemeMode = "dark" | "light" | "system";

interface Settings {
  theme: ThemeMode;
  editorFontSize: number;   // 编辑器字号
  codeFontSize: number;     // 代码字号
  defaultDir: string;       // 默认文档目录
}
```

- 状态管理：新建 `src/stores/settings.ts`（Pinia setup store），内部维护主题解析结果（`resolvedTheme: "dark" | "light"`），并把 `data-theme` 应用到 `document.documentElement`。

### 2.5 交互流程

1. 用户点击功能栏「设置」→ 弹出设置面板。
2. 修改主题单选 → 面板即时预览，`<html data-theme>` 立即切换。
3. 修改字号 → 编辑区/代码块字体即时变化（通过 CSS 变量 `--editor-font-size` / `--code-font-size` 或直接绑定）。
4. 关闭面板 → 设置已持久化，重启后保留。
