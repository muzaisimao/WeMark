# 子 PRD · M7 功能栏与设置

> 所属整体 PRD：`docs/PRD.md` 第 4、6 节
> 对应任务：T9
> 状态：设计中

## 1. 背景与目标

最左侧功能栏放置功能图标与设置入口，是全局操作的入口。本模块负责功能栏的图标布局与设置页。

## 2. 需求详述

### 2.1 功能栏

- 竖排图标：新建文档、打开文档/目录、搜索、设置等。
- 图标 hover 高亮与 tooltip 提示。
- 分工：功能栏放**全局/低频**操作；渲染区右上角放**当前文档相关**操作。

### 2.2 设置入口

- 点击设置图标打开设置面板（弹窗或独立视图）。
- 设置项（MVP）：
  - 主题（暗色/亮色）
  - 编辑器字体大小、代码字体
  - 默认文档目录
  - 图片附件存储位置（本地目录/图床，后续）

### 2.3 存储

- 设置项持久化（Tauri store 插件或本地 JSON），启动时加载。

## 3. 验收标准

- [ ] 功能栏图标齐全，点击可触发对应操作，有 tooltip。
- [ ] 设置面板可打开，主题切换即时生效。
- [ ] 设置项持久化，重启后保留。
