# 子 PRD · M1 项目骨架与四栏布局

> 所属整体 PRD：`docs/PRD.md` 第 4 节
> 对应任务：T1、T2、T11
> 状态：已完成（2026-10-20）

## 1. 背景与目标

WeMark 界面仿照 macOS 版微信，采用「四栏 + 底部输入区」布局。本模块负责项目骨架初始化（T1，已完成）与四栏静态布局、微信风主题的实现（T2）。

## 2. 需求详述

### 2.1 布局结构

```
┌──────┬────────────┬──────────────────────────────┐
│ 功能 │  文档列表  │        渲染区（聊天记录区）      │
│  栏  │            │        [右上角工具栏]           │
│      │  搜索框     │                              │
│      │  ▸ 文档树   │   · 内容块1                  │
│      │  ▸ 置顶项   │   · 内容块2                  │
│      │  ▸ 文档项   │   · 内容块3 ...              │
├──────┴────────────┴──────────────────────────────┤
│                编辑区（聊天输入区）                   │
│           [Markdown 输入框]                        │
│           [底部工具栏：格式/图片上传/草稿箱/发送]      │
└──────────────────────────────────────────────────┘
```

### 2.2 栏宽与尺寸

| 区域 | 建议尺寸 | 说明 |
|------|---------|------|
| 功能栏 | 约 60px 固定 | 图标竖排 |
| 文档列表栏 | 约 260px，可拖拽调整（180–400px） | 仿微信 |
| 渲染区 | 自适应（flex: 1） | 剩余空间，随两侧拖拽变化 |
| 编辑区 | 高约 160px，可拖拽调整（80–400px），随内容增长 | 底部固定 |

### 2.3 微信风主题（深色 / 浅色）

- 界面观感严格对照 macOS 版微信。
- 支持**深色**与**浅色**两套主题，通过 CSS 变量切换（`--bg`、`--panel`、`--text`、`--accent` 等）。
- 深色（默认）：深灰背景、浅色文字、绿色强调色（发送按钮）。
- 浅色：参照微信 macOS 浅色模式——浅灰背景、深色文字、绿色强调色。
- 主题切换入口在「设置」（见 `07-navbar-settings.md`），可选「跟随系统」。
- 圆角、阴影、hover 态贴近微信质感。

### 2.4 技术要点

- Vue 3 `<script setup>` + TypeScript。
- 状态管理 Pinia（栏宽、编辑区高、主题等布局状态入 store）。
- 组件拆分：`SideBar`（功能栏）、`DocList`（文档列表）、`RenderArea`（渲染区）、`EditorArea`（编辑区）。

### 2.5 区域拖拽调整大小

- 分隔线可拖拽：
  - **文档列表栏 ↔ 渲染区**之间的竖向分隔线：横向拖拽，调整文档列表栏宽度（渲染区宽度自适应）。
  - **渲染区 ↔ 编辑区**之间的横向分隔线：纵向拖拽，调整编辑区高度（渲染区高度自适应）。
- 尺寸约束：
  - 文档列表栏宽度：180–400px。
  - 编辑区高度：80–400px。
- 拖拽视觉反馈：分隔线 hover/拖拽时高亮，光标变为 `col-resize` / `row-resize`。
- 尺寸调整结果持久化（记入设置，重启后保留）。
