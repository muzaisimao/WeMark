# 子 PRD · M1 项目骨架与四栏布局

> 所属整体 PRD：`docs/PRD.md` 第 4 节
> 对应任务：T1、T2
> 状态：设计中

## 1. 背景与目标

WeMark 界面仿照 macOS 版微信，采用「四栏 + 底部输入区」布局。本模块负责项目骨架初始化（T1，已完成）与四栏静态布局、微信风主题的实现（T2）。

## 2. 需求详述

### 2.1 布局结构

```
┌──────┬────────────┬──────────────────────────────┐
│ 功能 │  文档列表  │        渲染区（聊天记录区）      │
│  栏  │            │        [右上角工具栏]           │
│      │  搜索框     │                              │
│      │  ▸ 文档树   │   · 内容块1                  │
│      │  ▸ 置顶项   │   · 内容块2                  │
│      │  ▸ 文档项   │   · 内容块3 ...              │
├──────┴────────────┴──────────────────────────────┤
│                编辑区（聊天输入区）                   │
│           [Markdown 输入框]                        │
│           [底部工具栏：格式/图片上传/草稿箱/发送]      │
└──────────────────────────────────────────────────┘
```

### 2.2 栏宽与尺寸

| 区域 | 建议尺寸 | 说明 |
|------|---------|------|
| 功能栏 | 约 60px 固定 | 图标竖排 |
| 文档列表栏 | 约 260px，可拖拽调整 | 仿微信 |
| 渲染区 | 自适应（flex: 1） | 剩余宽度 |
| 编辑区 | 高约 120–200px，随内容增长 | 底部固定 |

### 2.3 微信风主题

- 优先实现**暗色主题**（微信 macOS 默认），后续支持亮色切换。
- 配色：深灰背景、浅色文字、绿色强调色（发送按钮）。
- 实现方式：CSS 变量（`--bg`、`--panel`、`--text`、`--accent` 等），便于主题切换。
- 圆角、阴影、hover 态贴近微信质感。

### 2.4 技术要点

- Vue 3 `<script setup>` + TypeScript。
- 状态管理 Pinia（栏宽、主题等布局状态入 store）。
- 组件拆分：`SideBar`（功能栏）、`DocList`（文档列表）、`RenderArea`（渲染区）、`EditorArea`（编辑区）。

## 3. 验收标准

- [ ] 四栏布局正确呈现，栏宽符合预期，窗口缩放时渲染区自适应。
- [ ] 暗色主题配色与微信 macOS 观感接近。
- [ ] 各栏作为独立组件拆分，可单独开发与替换。
