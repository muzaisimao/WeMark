# 子 PRD · M9 渲染区交互增强

> 所属整体 PRD：`docs/PRD.md` 第 6 节（V1.1）
> 对应任务：T13（块号 + hover）、T15（块插入）、T16（滚动定位）、T17（分隔线修复）
> 状态：设计中

## 1. 背景与目标

渲染区已有「点击块回填编辑」的基础交互，但缺少：块号、清晰的 hover 反馈、块间插入能力、以及跨视图的滚动定位。本模块补齐这些，让块级编辑更直观、更好定位。

## 2. 需求详述

### 2.1 块号（T13）

- 每个块左侧固定显示序号 `1、2、3…`（对齐块内容左缘之外，形成 gutter 列）。
- 序号随块的新增/删除/插入**自动重排**。
- 块号与「正在编辑：第 N 块」提示条、搜索结果定位共用同一套序号语义（从 1 起、按文档顺序）。

### 2.2 hover 高亮（T13）

- 鼠标悬浮到块上时，有明确的高亮反馈。
- **不依赖背景色**（当前浅色下 `--hover` 太浅、代码块深色背景会盖住外层 hover），改为：
  - 左侧一条 accent 竖条（与块号 gutter 同列）；
  - 块外框描边（1px，accent 或中性色）；
  - 背景色作为辅助、可选。
- 深色/浅色两种主题下均清晰可见，代码块、表格、引用等所有块类型一致。

### 2.3 块插入（T15）

- 鼠标悬浮到某块时，该块**底部中央浮现 `+` 号**（浮层，绝对定位，不占用布局空间，避免块间距跳动）。
- 点击 `+` 号 → 在该块**下方**插入一个空块，编辑区自动进入「编辑该新块」态并聚焦。
- 输入发送后内容原位填入该新块（复用 `editing → 替换` 逻辑）。
- 块号自动重排；`+` 号在编辑态隐藏（避免与正在编辑冲突）。
- 「上方插入」MVP 不做（等价于上一个块的下方插入）。

### 2.4 滚动定位（T16）

- 触发场景：点击某块进入编辑、或搜索结果跳转到某块时，若该块**不在渲染区可视范围内**，自动滚动使其进入视野。
- 滚动策略：目标块对齐到渲染区中部（或顶部留少量边距），平滑滚动。
- 不打扰：仅在目标块当前不可见时才滚动，可见时保持不动。

### 2.5 分隔线修复（T17）

- 问题：文档区 ↔ 渲染区的**竖分隔线**（`v-resizer`）未 hover 时仍占 4px 空间，视觉上形成一条「空竖线」；而编辑区 ↔ 渲染区的横分隔线无此问题。
- 目标：竖分隔线未 hover 时**不产生视觉缝隙**（与两侧面板自然衔接），hover / 拖拽时才显示绿色高亮，与横分隔线行为一致。
- 实现方向：调整 `v-resizer` 的布局（负 margin / 绝对定位 / 背景融合），保留拖拽热区不变。

## 3. 验收标准

- [ ] 每个块左侧显示正确序号，增删/插入后自动重排。
- [ ] hover 高亮在深浅色下、代码块/表格/引用上均清晰可见。
- [ ] hover 块底部出现 `+` 号，点击后在下方插入空块并进入编辑，发送后原位填入。
- [ ] 点击不可见块 / 搜索跳转时自动滚动到目标块。
- [ ] 竖分隔线未 hover 无空缝，hover/拖拽显示绿色，与横分隔线一致。
