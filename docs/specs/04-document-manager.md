# 子 PRD · M4 文档管理

> 所属整体 PRD：`docs/PRD.md` 第 6 节
> 对应任务：T6
> 状态：已完成

## 1. 背景与目标

文档列表栏仿微信「聊天列表」，用于管理本地 `.md` 文档，支持置顶、树级展开，顶部搜索框可同时搜索文档名与文档内容。

## 2. 需求详述

### 2.1 文档列表

- 展示文档名称，按「最近编辑时间」排序（仿微信按最近聊天排序）。
- 当前打开文档高亮。

### 2.2 置顶

- 文档可置顶，置顶项固定在列表顶部，与普通项分区显示。
- 置顶/取消置顶操作（右键菜单或 hover 按钮）。

### 2.3 树级展开

- 文档可组织为目录树（对应磁盘目录），支持折叠/展开子目录。
- 树节点：目录（可展开）+ 文档（可打开）。

### 2.4 搜索

- 顶部搜索框，同时搜索**文档名**与**文档内容**。
- 输入即时过滤列表；命中内容时展示匹配文档与匹配片段。
- 点击搜索结果跳转到对应文档（后续支持定位到具体块）。

## 3. 验收标准

- [x] 文档列表按最近编辑排序，当前项高亮。
- [x] 置顶/取消置顶生效，置顶项固定顶部。
- [x] 目录树可折叠/展开。
- [x] 搜索能匹配文档名与文档内容，结果可跳转。

## 4. 涉及任务

- T6：实现文档列表（置顶、树级展开、搜索）。
