# 子 PRD · M6 文件系统集成

> 所属整体 PRD：`docs/PRD.md` 第 6 节
> 对应任务：T8
> 状态：设计中

## 1. 背景与目标

文档以本地 `.md` 文件存储，通过 Tauri 文件系统直接读写磁盘，实现「文档即文件」。本模块负责新建/打开/保存文档，以及文档树与磁盘目录的同步。

## 2. 需求详述

### 2.1 核心能力

- **新建文档**：创建新 `.md` 文件。
- **打开文档**：通过文件选择器打开已有 `.md`。
- **保存文档**：将当前文档的块序列化回 Markdown 源码，写回磁盘。
- **打开目录/工作区**：选择目录作为文档树根，展示目录内 `.md` 结构。

### 2.2 数据流

```
磁盘 .md 文件 ──读──► 解析 ──► Block[] ──► 渲染
                                    ▲
                                    │ 编辑
Block[] ──序列化──► Markdown 源码 ──写──► 磁盘 .md 文件
```

- 文档加载：读文件 → 解析为块 → 渲染。
- 文档保存：块 → 序列化为源码 → 写文件。

### 2.3 Tauri 实现

- Rust 侧提供命令：`read_file`、`write_file`、`list_dir`、`pick_file`（文件选择器）。
- 使用 `@tauri-apps/plugin-dialog`（文件选择）与 `@tauri-apps/plugin-fs`（文件读写），或自写命令。
- 在 `capabilities/default.json` 声明所需权限（fs、dialog）。

## 3. 验收标准

- [ ] 能新建、打开、保存 `.md` 文件。
- [ ] 保存后磁盘文件内容正确（块序列化无损）。
- [ ] 文档树正确反映磁盘目录结构。
- [ ] 权限配置齐全，无权限报错。
